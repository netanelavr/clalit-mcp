# Security

## Reporting

Do **not** open a public issue for vulnerabilities that could expose medical records, session cookies, or authentication weaknesses.

Email the maintainer via GitHub: https://github.com/netanelavr — use a private advisory if available on this repository (`Security` → `Report a vulnerability`).

Include:

- Description and impact
- Reproduction **without** real PHI, real cookies, or full HAR dumps
- Sanitized HTML snippets or redacted maps only

## Project rules

- No CAPTCHA, Imperva, or SMS OTP bypass code will be accepted.
- No commits of `*.har`, cookies, `session.json`, or personal lab PDFs.
- Own-account reads only; family-member switching is out of scope and refused.
